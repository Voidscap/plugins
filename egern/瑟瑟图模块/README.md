# 瑟瑟图模块

Egern 小组件：从 yande.re / Konachan 按标签取动漫插画，按小组件尺寸匹配画幅，免登录。

来源：https://github.com/a13609y/yandere-widget ，作者 Cuttlefish。本目录只放了 `yandere.yaml`，脚本仍从原仓库加载（yaml 里的 `script_url` 未改）。

## 安装

Egern → 模块 → 右上角 + → 从 URL 导入：

```
https://raw.githubusercontent.com/Voidscap/plugins/main/egern/瑟瑟图模块/yandere.yaml
```

## 默认设置

- 分级：全年龄（s）开、擦边（q）开、工口（e）关
- 过滤：萝莉正太（loli / shota）默认开，已排除
- 换图间隔：30 分钟，防重复 100 张

想改标签、分级或过滤，在 Egern 模块设置里改就行。
